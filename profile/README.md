# 岡大AIStudio

### AIを学び、つくり、共有する。

岡大AIStudioは、岡山大学の学生有志による**非公認AI開発サークル**です。

AIに興味のある学生が集まり、自由に学び、開発し、交流できる場所を目指しています。

## 活動内容

- **AI開発**：AIを活用したアプリやサービスの個人開発・共同開発
- **情報共有**：最新AIニュース、開発ツール、技術ノウハウの共有
- **成果発表**：開発成果や学んだことの紹介
- **交流**：勉強会やイベントを通じた交流
